# Web Applications

A collection of full-stack web applications I've built to explore modern
web development, APIs, databases, data-driven interfaces, and
production-focused architecture.

Projects in this repository range from experiments and prototypes to
more complete applications.

## Projects

### Rental Property Finder
A full-stack rental property discovery and mapping application.

**Tech:** React, TypeScript, Express, PostgreSQL, MapLibre, Docker

Features currently include:
- Interactive property map
- Property search and filtering
- PostgreSQL-backed property data
- Custom Express REST API
- Responsive React interface
- Geographic property visualization

> This project is actively being developed and may evolve into a broader
> rental market analytics platform.
